# Vinheria Agnello — Frontend Practice

A collection of HTML and CSS exercises built around a wine shop theme. The repository includes a static landing page and layout practice.

## Repository structure

| Directory | Contents |
| --- | --- |
| `vinheria/` | Wine shop landing page, styles, and supporting assets |
| `grid-arquivos/` | Grid layout practice files |
| `aula0905/` | Additional class exercises |

## Technology

- HTML
- CSS
- Google Fonts

## Run locally

```bash
git clone https://github.com/vitorrampazzi/Vinheria_Agnello_Treino.git
cd Vinheria_Agnello_Treino
```

Open `vinheria/index.html` in a browser. You can also use a local static server, such as the Live Server extension for Visual Studio Code.

## Scope

This is a frontend learning project. The landing page contains placeholder text and sections for layout practice. The repository does not currently provide a shopping backend, authentication, payment processing, or order management.
